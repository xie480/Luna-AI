# Luna 用户画像与偏好建模方案

## 1. 章节目标

本文档定义 Luna 系统如何基于长期记忆系统，构建和维护用户画像（User Profile）与偏好（Preference）模型。系统通过 Python 后端对用户交互数据进行结构化分析，提取事实、偏好、习惯等信息，形成可检索、可更新的用户画像。

## 2. 核心设计

用户画像是长期记忆（LTM）系统的一个特殊域，本质上是 `domain=RELATIONSHIP, type=SEMANTIC` 的记忆事实集合。

### 2.1 Python 端管理全链路

Python Backend 的 Memory Manager 统一负责：

1. **提取**：从用户对话中通过 LLM 提取偏好事实（如"用户喜欢极简风格"）。
2. **合并**：与已存储的用户画像进行冲突检测与合并。
3. **持久化**：写入 PostgreSQL + Qdrant。
4. **检索**：在 Agent 推理时自动注入相关用户画像到 Prompt。

### 2.2 用户画像数据结构

```python
from pydantic import BaseModel, Field
from typing import Optional, Literal

class UserProfileFact(BaseModel):
    """用户画像事实"""
    fact_id: str = Field(..., description="雪花算法 ID")
    category: Literal["preference", "habit", "identity", "knowledge", "emotion_pattern"]
    content: str = Field(..., description="事实描述，如 '用户喜好无糖咖啡'")
    confidence: float = Field(default=1.0, ge=0.0, le=1.0)
    source: str = Field(..., description="来源，如 '聊天推理'、'用户直接声明'")
    created_at: Optional[str] = None
```

## 3. 偏好提取流程 (Python)

1. 用户对话完成后，Python Memory Manager 调用 LLM 分析增量文本。
2. LLM 返回结构化偏好事实列表（`List[UserProfileFact]`）。
3. Python 对比现有画像库，检测冲突（如旧偏好"用户喜欢甜咖啡" vs 新输入"我现在只喝无糖"）。
4. 执行 UPDATE + 软删除旧事实。
5. 写入 PostgreSQL + Qdrant 向量化。

## 4. 画像注入与使用

在 Agent 推理阶段，Python 自动检索 Top-5 相关用户画像事实，注入到 System Prompt：

```python
system_prompt = f"""
你是 Luna，一名 AI 桌面助理。

关于用户的已知信息：
{format_user_profile(relevant_facts)}

请基于以上信息，以符合用户偏好的方式回答问题。
"""
```

## 5. 落地实施建议

1. **Phase 1**：实现基础偏好提取和存储（PostgreSQL 存储，手动注入 Prompt）。
2. **Phase 2**：实现冲突检测与自动合并机制。
3. **Phase 3**：接入 Qdrant 向量检索，实现动态画像注入。
