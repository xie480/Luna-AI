# Web Search Skill — 通用搜索建议和推荐最佳实践

## 概述

本文档提供了基于 SearXNG 元搜索引擎的通用搜索建议和推荐最佳实践。SearXNG 是一个自托管的、尊重隐私的元搜索引擎，聚合了 Google、Bing、DuckDuckGo 等多个搜索引擎的结果。本文档旨在帮助开发者和使用者充分利用搜索能力。

> **适用读者**：AI Agent 开发人员、Skill 配置管理者、高级用户。

---

## 一、SearXNG 部署建议

### 1.1 本地部署（推荐）

```bash
# 使用 Docker 快速部署 SearXNG
docker run -d \
  --name searxng \
  -p 8888:8080 \
  -e BASE_URL=http://localhost:8888 \
  -e SEARXNG_SECRET_KEY=$(openssl rand -hex 32) \
  searxng/searxng:latest
```

### 1.2 启用 JSON API 支持

默认 SearXNG 的 JSON API 可能未启用，需要修改 `searxng/settings.yml` 配置文件：

```yaml
search:
  # 确保以下格式被启用
  formats:
    - html
    - json
```

如果 JSON API 未启用，搜索工具将无法解析返回结果并提示配置错误。

### 1.3 性能调优建议

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| `search.safe_search` | 1 | 0=关闭，1=中等，2=严格 |
| `search.autocomplete` | google | 自动补全引擎 |
| `server.limiter` | false | 开发环境建议关闭限流 |
| `outgoing.request_timeout` | 5.0 | 上游搜索引擎超时（秒） |

## 二、搜索参数最佳实践

### 2.1 query（查询词）的构造技巧

| 场景 | 推荐做法 | 示例 |
|------|---------|------|
| 精确搜索 | 使用引号包裹关键词 | `"2024年诺贝尔物理学奖"` |
| 排除干扰 | 使用减号排除无关内容 | `Python教程 -爬虫` |
| 站点限定 | site: 语法（需后端引擎支持） | `site:zhihu.com AI 绘画` |
| 文件类型 | filetype: 语法（需后端引擎支持） | `filetype:pdf 机器学习` |

### 2.2 categories（搜索分类）的选择策略

| 分类 | 适用场景 | 建议搭配的引擎 |
|------|---------|---------------|
| `general` | 通用信息搜索，默认值 | google, bing, duckduckgo |
| `news` | 新闻、时事、最新动态 | google news, bing news |
| `science` | 学术论文、科学发现 | google scholar, semantic scholar |
| `it` | 技术文档、编程相关 | stackoverflow, github |
| `social media` | 社交媒体内容 | reddit, twitter |
| `files` | 文档文件搜索 | google files, bing files |
| `images` / `videos` | 多媒体内容 | google images, bing images |

### 2.3 language（语言）的选配建议

| 语言代码 | 适用场景 |
|---------|---------|
| `zh-CN` | 简体中文内容，用户母语搜索 |
| `zh-TW` | 繁体中文内容 |
| `en-US` | 英文内容，技术文档优先 |
| `ja-JP` | 日文内容 |
| `auto` | 自动检测（部分 SearXNG 版本支持） |

### 2.4 engines（搜索引擎）的选配建议

| 引擎名称 | 优势 | 劣势 |
|---------|------|------|
| `google` | 覆盖面最广，结果最准确 | 可能被限制访问 |
| `bing` | 中文结果较好，稳定 | 结果数略少 |
| `duckduckgo` | 隐私友好，无需 API Key | 中文结果质量一般 |
| `stackoverflow` | 编程问答质量极高 | 仅限技术问答 |
| `wikipedia` | 百科类信息权威 | 覆盖范围有限 |

## 三、渐进式搜索策略

### 3.1 标准四段搜索流程

```
[第一轮] 宽泛查询 → 获取概览 → 识别关键词领域
    ↓
[第二轮] 精确查询 → 聚焦关键信息 → 验证初步结论
    ↓
[第三轮] 补充查询 → 填补信息缺口 → 交叉验证
    ↓
[第四轮] 确认查询 → 权威来源背书 → 最终整合输出
```

### 3.2 各轮次参数调整建议

| 轮次 | 查询词策略 | 分类 | 语言 | 结果数 |
|------|-----------|------|------|--------|
| 第1轮 | 自然语言长句 | general | zh-CN | 10 |
| 第2轮 | 核心关键词组合 | 根据内容调整 | 目标语言 | 10 |
| 第3轮 | 特定实体+限定词 | 细分分类 | 切换备选语言 | 15 |
| 第4轮 | 精确短语/站点限定 | 权威站点 | 原文语言 | 5 |

### 3.3 搜索退出条件

当满足以下任一条件时，应终止搜索循环：

1. **信息充分**：已找到足够权威、覆盖核心问题的信息。
2. **结果收敛**：连续两轮搜索未发现新的相关信息。
3. **超时**：已执行超过 4 轮搜索仍无法找到目标信息时，应将当前结果整合输出并标注"部分结果"。
4. **用户中断**：用户明确表示已获得所需信息。

## 四、信息可信度评估框架

### 4.1 来源评级

| 等级 | 类型 | 示例 | 可信度 |
|------|------|------|--------|
| S级 | 官方/权威 | 政府网站 (.gov)、学术论文 (DOI) | 极高 |
| A级 | 知名机构 | 新闻媒体、行业报告、Wiki | 高 |
| B级 | 专业平台 | 技术博客、Stack Overflow、知乎 | 中高 |
| C级 | 用户生成 | 论坛、个人博客、社交媒体 | 中等 |
| D级 | 未经验证 | 匿名来源、自媒体的推测性内容 | 低 |

### 4.2 时效性评估

- **新闻/事件类**：优先选择 24 小时内的来源。
- **技术/教程类**：优先选择 1 年内的来源，标注发布时间。
- **百科/概念类**：关注版本号/最后更新时间，而非首次发布时间。
- **数据/统计类**：明确标注数据采集年份，过时数据（>3 年）标注"可能已过时"。

### 4.3 交叉验证规则

- **单来源断言**：标注"根据单一来源"。
- **双来源一致**：可视为"较可靠"。
- **三来源及以上一致**：可视为"可靠"。
- **来源矛盾**：同时呈现矛盾方观点，标注分歧。

## 五、多语言搜索策略

### 5.1 中文优先原则

1. 第一轮始终使用中文（zh-CN）搜索。
2. 如果中文结果不足或质量低，切换至英文（en-US）。
3. 如果英文搜索结果也无法满足，考虑使用目标国家语言搜索。

### 5.2 语言切换条件

| 场景 | 建议 |
|------|------|
| 中文搜索结果 < 3 条 | 切换至英文搜索 |
| 中文结果相关性明显不足 | 切换至英文并调整查询词 |
| 技术/编程问题 | 中英文并行搜索 |
| 特定国家/地区信息 | 使用该国官方语言搜索 |

## 六、错误处理与降级策略

### 6.1 常见错误码及处理

| 现象 | 可能原因 | 处理建议 |
|------|---------|---------|
| HTTP 404 | SearXNG 路径错误 | 检查 `SEARXNG_BASE_URL` 配置 |
| HTTP 429 | 请求频率过高 | 增加请求间隔或减少并发 |
| 连接超时 | 服务不可达 | 检查网络、防火墙、Docker 容器状态 |
| 空结果 | 查询词不当或引擎受限 | 更换查询词，尝试不同分类/引擎 |
| JSON 解析失败 | JSON API 未启用 | 确认 `searxng.yml` 中启用 `json` 格式 |

### 6.2 降级策略

当 SearXNG 完全不可用时：

1. **第一级**：报告配置错误并提供配置指引。
2. **第二级**：告知用户搜索服务暂时不可用，建议稍后重试。
3. **第三级**：不降级使用任何其他搜索引擎 API（遵循本地优先原则，不引入外部依赖）。

## 七、隐私与安全注意事项

1. **SearXNG 默认不记录 IP 地址**：SearXNG 设计上不保存用户搜索日志，符合隐私优先原则。
2. **建议本地部署**：SearXNG 只能部署在本地或局域网内，避免通过公网暴露。
3. **敏感搜索**：避免在搜索结果中暴露个人敏感信息。搜索工具的输出会经过 `4096` 字符截断和清理。
4. **HTTPS 加密**：如果必须暴露到公网，建议配置 HTTPS 和反向代理认证。

## 八、搜索参数快速参考

| 参数名 | 类型 | 必填 | 默认值 | 最大 | 说明 |
|--------|------|------|--------|------|------|
| `query` | string | ✅ | — | 500字符 | 搜索查询词 |
| `categories` | string | ❌ | `general` | — | 分类，多个用逗号分隔 |
| `engines` | string | ❌ | （SearXNG默认） | — | 引擎，多个用逗号分隔 |
| `language` | string | ❌ | `zh-CN` | — | ISO 639-1 语言代码 |
| `pageno` | integer | ❌ | `1` | 50 | 页码 |
| `safesearch` | integer | ❌ | `1` | 2 | 0=关闭，1=中等，2=严格 |
| `max_results` | integer | ❌ | `10` | 50 | 返回结果数量上限 |
